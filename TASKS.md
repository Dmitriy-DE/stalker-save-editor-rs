## Как работаем

- **Кодекс** пишет код. ChatGPT больше не участвует. **Облачный Claude** — интегратор: проверяет PR, собирает
  пересекающиеся в `integrate/<имя>`, чинит конфликты, вливает, пишет этот файл. **Владелец** проверяет в игре и
  выпускает релиз.
- `main` защищён: только PR, зелёные `check (ubuntu-24.04)`, `check (windows-latest)`, `check (macos-14)`.
- Один пункт = одна ветка `wp/<ID>-<кратко>` от свежего `main` = один PR. Новый PR на ту же задачу не открывать —
  пушить в старую ветку.
- Перед пушем: `cargo fmt --all`, `cargo clippy --workspace --all-targets -- -D warnings`,
  `cargo test --workspace` **целиком**; для `sse-sys` ещё
  `cargo clippy -p sse-sys --target x86_64-pc-windows-gnu -- -D warnings`.
- В PR: что запускал и что не проверено (игру, Steam и живые окна агенты не запускают).
- Нельзя: писать в настоящие сейвы, в Steam, трогать ключ подписи; новые `.md` кроме пяти документов
  (README, AGENTS, PLAN, TASKS, ACCEPTANCE).

## Выпуск релиза (владелец или его локальный Claude с доступом к ключу)

Облачные агенты ключ не трогают. Ключ подписи — `~/.config/stalker-save-editor/update-signing-key.pem`; его
открытый ключ совпадает с `PUBLIC_KEY_PEM` в `crates/sse-update/src/signature.rs` (сверено 2026-10-06).

1. Actions → `ci` → Run workflow на нужном коммите (или тег `v<версия>`): задача `packages` даёт
   `packages-Linux` (tar.gz, deb, Windows zip) и `packages-macOS` (dmg).
2. Скачать оба артефакта в одну папку `dist/`, затем `tools/package.sh --manifest-only` → `dist/latest.json` и
   пустой `dist/latest.json.sig`.
3. Подпись (ECDSA P-256/SHA-256, DER, base64):
   `openssl dgst -sha256 -sign ~/.config/stalker-save-editor/update-signing-key.pem dist/latest.json | base64 -w0 > dist/latest.json.sig`.
   Перед первой подписью: `openssl pkey -in <ключ> -pubout` должен совпасть с `PUBLIC_KEY_PEM`.
4. Выкладка в R2 (`CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`):
   `npx wrangler r2 object put save-editor-downloads/<файл> --file dist/<файл> --remote` для каждого пакета;
   **`latest.json.sig`, затем `latest.json` — последними**. Образец всей процедуры —
   `tools/release/publish_release.py` в старом C#-репозитории.
5. Проверка: `curl -sI https://save-editor-downloads.save-editor.workers.dev/latest.json`; старая версия
   редактора должна предложить обновление.

Отчёты об ошибках пользователей лежат в том же бакете, папка `diagnostics/`.
